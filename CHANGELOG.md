## [Unreleased]

### Added
- Project architecture documentation.

- Security rules documentation.
- Development roadmap.
- Project README with implementation status.

### Implemented
- Python source-file scanning.
- Recursive directory scanning.
- AST-based detection of direct `eval()` calls.
- Structured Finding data model.
- File-level scanning error handling.
- Safe and vulnerable sample source files.

### Known Limitations
- Only direct `eval()` calls are detected.
- No automated test suite has been established yet.
- JSON report generation is not implemented.
