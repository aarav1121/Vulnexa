\# Vulnexa



Vulnexa is a custom Static Application Security Testing (SAST)

engine developed in Python.



\## Project Goal



To build our own static code analysis engine capable of identifying

potential security vulnerabilities in Python source code.



\## Core Components



\- Python AST Parser

\- Code Analyzer

\- Symbol and Scope Analysis

\- Control Flow Graph (CFG)

\- Data Flow Analysis

\- Taint Analysis

\- Custom Security Rule Engine

\- Vulnerability Reporting



\## Technology Stack



\- Python 3.13+

\- Python AST

\- Git and GitHub

\- pytest (planned)



\## Project Status



Currently in the foundation and code-understanding phase.



\## Important



Vulnexa analyzes source code statically. It does not execute

the scanned application's code.
